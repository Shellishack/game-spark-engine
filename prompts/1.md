I am trying to make a new AI native interative game engine. The idea is Cursor.ai but for web-based game engines.

Core infra and stack:
- PlayCanvas for 3D and 2.5D game engine
- Electron for desktop app
- Local file system for asset management and storage
- Web based framework for UI, use React.

## Visual assets generation
   - 2D sprite sheet assets for characters. Image 2 can generate up to 1024x1024 pixels. So you will create multiple images for each character. Each image will be 4 by 3 frames (12 frames, each frame will be 3:4), which means each image will have 16 frames. You will create different images for different emotions including idle, walk, laugh, confused, sad, angry, surprised. Name the file like so [character]_[emotion].png. For example, if the character is a cat, you will create cat_idle.png, cat_walk.png, cat_laugh.png, cat_confused.png, cat_sad.png, cat_angry.png, cat_surprised.png.
   - 3D model for scene and objects. You will use this skill to generate 3D models for the scene https://github.com/neilsonnn/image-blaster
